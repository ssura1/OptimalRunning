# iPhone

`OptimalRunner.xcodeproj`, iOS 17.0+. Generated by [xcodegen](https://github.com/yonaskolb/XcodeGen) from `project.yml` — **do not hand-edit the `.xcodeproj`**; edit `project.yml` and run `xcodegen generate` from this directory.

This target owns **only** platform glue: SwiftUI views, persistence, HealthKit reads,
and the sync transport. Every decision it renders comes from `Core` (ADR-001), so this
directory should contain no pace maths, no zone logic and no interval rules.

```sh
xcodegen generate   # regenerate the .xcodeproj after editing project.yml
xcodebuild test -project OptimalRunner.xcodeproj -scheme OptimalRunner \
  -destination 'platform=iOS Simulator,name=iPhone 15'
```
